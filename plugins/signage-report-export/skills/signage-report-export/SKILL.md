# 前提

- 午前・午後・夜を別表にせず、1つの横長表として扱う。
- 会場名の行は予約がない日も固定表示する。
- 手動の会場データとTableCheck自動データを選択して出力できるようにする。

# 手順

1. データ元と対象日を選択する。
2. 予約を時間帯へ分類し、会場名を正規化して固定会場行へ割り当てる。
3. 複数予約は同じセル内で縦に積み、人数・時間・備考も予約単位で対応させる。
4. PDF出力は画面の横長表を印刷用レイアウトで出力する。
5. Excel出力は、現在表示中の表と同じデータ・時間帯・固定行をダウンロード可能な形式にする。
6. 日本語、空欄行、複数会場、終了時刻、備考の表示を確認する。

# 注意点

- 一覧画面と帳票で表示要件が異なる項目（例: 終了時刻）は、帳票側だけに追加する。
- 会場名の変換設定と個別の場所設定の優先順位を崩さない。
- 出力ファイルにAPIキー、認証情報、内部ハッシュを含めない。
