# 前提

- 手続の正式名は「特定非営利活動法人の変更登記（役員変更）」。理事長が続投する場合は「理事長の重任」。法務局の予約フォームの手続内容にもこの名前で書く。
- 登記されている役員は、定款で代表権を持つと決めた者だけ（例：理事長のみが代表する定款なら理事長だけ）。同じ人が続投しても、任期満了ごとに登記が必要。
- 役員の任期は定款で決めた2年以内（特定非営利活動促進法 第24条）。任期2年の法人は2年に1回この登記が必要。
- 変更が生じてから2週間以内に登記する（組合等登記令 第3条1項）。期限を過ぎても義務は残るので、気づいた時点で申請する。
- 「資産の総額」の毎年の変更登記は不要（組合等登記令 別表から削除済み）。
- 登録免許税はかからない。
- 書式は法務省のNPO法人の記載例・様式に合わせる：https://houmukyoku.moj.go.jp/homu/COMMERCE_11-1.html （「ＮＰＯ法人役員変更登記申請書（理事全員重任）」）

# 手順

1. 定款を読み、任期・理事長の選び方（理事の互選か）・代表権の定め・任期伸長の定めの有無を確認する。前回の議事録・互選書・申請書の控えと、最新の登記事項証明書も用意する。
2. 社員総会議事録を作る。任期満了日まで（満了日当日まで）に総会を開いて、理事を改選（重任）する。
3. 理事の互選書を作る。本来は、新しい任期が始まってから（任期満了日の翌日以降）理事が集まって理事長を選ぶのが望ましい。理事全員が同じ顔ぶれで重任する場合は、総会と同じ日でもよい（法務局確認済み）。
4. 変更登記申請書を作る。
   - 登記の事由：理事長の重任
   - 登記すべき事項：資格・住所・氏名・原因年月日（例：令和○年6月1日重任）。法務省の記載例では資格を「理事」と書く。どちらで書くかは管轄の法務局の指示に従う。
   - 申請人：現在の理事長。法務局に届けている印を押す。
   - 添付書類：社員総会議事録、互選書、定款（各1通）。就任承諾書は、議事録・互選書に「席上就任を承諾」と書いてあればそれで足りる。
5. 定款の写しを添付する（商業登記規則 第61条1項。各種法人等登記規則 第5条で準用）。写しの最後に証明文を入れ、理事長が記名押印する。
   - 例：「以上は、当法人の現行定款に相違ありません。」＋日付＋主たる事務所＋法人名＋理事長の住所＋「理事長 氏名 印」
   - 文言は法令で決まっておらず、法務局の実務。書く場所は最後でよい。
6. 出す前に、法務局の登記手続案内（予約制）で確認する。
   - 予約：https://www.legal-ab.moj.go.jp/houmu.home-t/ →管轄の法務局を選ぶ →「会社・法人登記手続案内」
   - 手続案内は書類の事前チェックはせず、書き方の一般的な説明だけ。聞きたいこと（日付・添付書類・住所の訂正）を絞って持っていく。
7. 所轄庁（都道府県または指定都市）に「役員変更等届出書」と「変更後の役員名簿」を出す（特定非営利活動促進法 第23条）。任期満了と同時に再任した場合は、就任承諾書・誓約書と住所の証明書は要らない。

# 注意点

- 総会の日を任期満了日の翌日以降にすると、「任期満了と同時の再任」にならない。法務局から直すよう言われることがある。総会は任期満了前に開く。
- 役員の住所は書類ごとにぶれやすい。住民票・登記簿どおりに全書類で統一する。
- 日付は実際に総会・互選をした日を書く。書類の作成日を合わせるために日付を遡らせない。
- 毎年の手続（事業報告書等を所轄庁へ出す（事業年度終了後3か月以内）、貸借対照表の公告）は、この登記とは別にある。
