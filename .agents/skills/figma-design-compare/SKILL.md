# Figma とデザイン画像の突き合わせ

## 前提

- Figma URL はユーザーのメッセージから **そのままコピー** する（`%25EF%25BC%2586` のように二重エンコードされたファイル名部分を含む）。短縮・再エンコードすると 404 になる。ファイルキーは `figma.com/design/<KEY>/...` の `<KEY>` 部分。
- Figma は Chrome（computer ツール）で開く。閲覧権限があれば未ログインでも見られる。API トークンが無ければ画面キャプチャベースで比較する。
- 比較対象の画像は `/home/ubuntu/attachments/...` にダウンロード済み。`read` で画像を開けば内容を読める。

## 手順

1. **画像側の棚卸し**: 添付画像を上から順に読み、「セクション名 / 見出し文言 / ボタン文言とリンク先 / 件数（カード数・コース数）/ 配色・トーン」を表にする。
2. **Figma を開く**: 左ペインの Pages → 該当フレーム（TOP等）を選び、`Shift+1`（全体表示）→ ズームしながらスクロールし、同じ項目を表にする。長いフレームは上から数回に分けてスクリーンショットを撮る。
3. **差分整理**: 表を突き合わせ、次の3区分で列挙する。
   - **構成・文言の差**（セクション順、見出し・コース名・料金・電話番号の相違）→ 実装に影響。必ずユーザー確認。
   - **導線の差**（ボタンのリンク先、CTAの有無）→ 実装に影響。
   - **見た目のみの差**（配色、写真、装飾、アイコン）→ どちらを基準にするかだけ確認。
4. **報告**: 「大きな矛盾なし／あり」を1行で結論し、差分は箇条書き（例:「3つ目のコース名が『1Day・半日集中個人レッスン』→『1Day・半日個人レッスン』」）。どちらを基準に進めるか1問だけ聞く。
5. ユーザーが基準を指定したら、基準側のトーン（配色・角丸・カード形状）で実装し、基準に無い要素はもう一方から補完する。

## 注意

- Figma は最新、静止画像は古いことが多い。料金・電話番号・固有名詞は Figma 側と一致しているかを特に確認する。
- 下層ページの Figma が無い場合（コラム詳細など）は「一覧のトーンに合わせて作る」と明記して進める。
- 画像・動画・地図など素材未提供の箇所はプレースホルダー（`※〜が入ります`）で実装し、報告時に一覧で示す。
